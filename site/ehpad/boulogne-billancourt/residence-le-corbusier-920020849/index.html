Où se situe ce tarif

93e tarif le plus bas sur les 94 EHPAD dans les Hauts-de-Seine ayant déclaré le leur — plus cher que 98 % d’entre eux. Parmi les 55 établissements privés commerciaux du département, le tarif médian est de 4 270 € par mois : celui-ci est 44 % plus élevé. À Boulogne-Billancourt, médiane de 2 561 € sur 5 établissements : 141 % plus cher. Médiane nationale : 2 245 € (+174 % pour cet établissement).
