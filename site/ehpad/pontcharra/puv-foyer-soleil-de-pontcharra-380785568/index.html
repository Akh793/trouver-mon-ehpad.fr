Où se situe ce tarif

1er tarif le plus bas sur les 84 EHPAD en Isère ayant déclaré le leur — plus cher que 0 % d’entre eux. Parmi les 32 établissements associatifs du département, le tarif médian est de 2 415 € par mois : celui-ci est 35 % plus bas. Médiane nationale : 2 245 € (-30 % pour cet établissement).
