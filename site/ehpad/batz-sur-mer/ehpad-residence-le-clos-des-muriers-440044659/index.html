Où se situe ce tarif

139e tarif le plus bas sur les 150 EHPAD en Loire-Atlantique ayant déclaré le leur — plus cher que 92 % d’entre eux. Parmi les 17 établissements privés commerciaux du département, le tarif médian est de 3 736 € par mois : celui-ci est 8 % plus bas. Médiane nationale : 2 246 € (+53 % pour cet établissement).
