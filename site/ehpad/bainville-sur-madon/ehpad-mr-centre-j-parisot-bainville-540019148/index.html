Où se situe ce tarif

15e tarif le plus bas sur les 42 EHPAD en Meurthe-et-Moselle ayant déclaré le leur — plus cher que 33 % d’entre eux. Parmi les 18 établissements associatifs du département, le tarif médian est de 2 375 € par mois : celui-ci est 8 % plus bas. Médiane nationale : 2 245 € (-3 % pour cet établissement).
