Où se situe ce tarif

109e tarif le plus bas sur les 116 EHPAD dans l’Hérault ayant déclaré le leur — plus cher que 93 % d’entre eux. Parmi les 35 établissements privés commerciaux du département, le tarif médian est de 3 020 € par mois : celui-ci est 11 % plus élevé. Médiane nationale : 2 245 € (+49 % pour cet établissement).
