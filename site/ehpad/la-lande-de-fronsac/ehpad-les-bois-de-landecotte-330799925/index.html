Où se situe ce tarif

81e tarif le plus bas sur les 133 EHPAD en Gironde ayant déclaré le leur — plus cher que 60 % d’entre eux. Parmi les 69 établissements privés commerciaux du département, le tarif médian est de 3 264 € par mois : celui-ci est 7 % plus bas. Médiane nationale : 2 245 € (+34 % pour cet établissement).
