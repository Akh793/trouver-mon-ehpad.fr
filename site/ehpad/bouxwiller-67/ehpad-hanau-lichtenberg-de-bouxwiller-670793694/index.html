Où se situe ce tarif

42e tarif le plus bas sur les 89 EHPAD dans le Bas-Rhin ayant déclaré le leur — plus cher que 46 % d’entre eux. Parmi les 40 établissements publics du département, le tarif médian est de 2 089 € par mois : celui-ci est 5 % plus élevé. Médiane nationale : 2 245 € (-2 % pour cet établissement).
