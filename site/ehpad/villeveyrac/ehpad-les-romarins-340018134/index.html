Où se situe ce tarif

97e tarif le plus bas sur les 116 EHPAD dans l’Hérault ayant déclaré le leur — plus cher que 83 % d’entre eux. Parmi les 35 établissements privés commerciaux du département, le tarif médian est de 3 020 € par mois : celui-ci est au même niveau. Médiane nationale : 2 245 € (+34 % pour cet établissement).
